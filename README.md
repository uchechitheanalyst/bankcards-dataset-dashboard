## Recommendations
- Advertisements and promotions should be intensified during the first two months of every year.
- In order to avoid a recurrence of such, the reason for a decline in the number of account openings from 2011 to 2019 should be investigated.
## Limitations
- Details on the number of cards held by each client was ambiguous. Hence, the number of cards held by each client per time could not be ascertained.
- The credit limit would have served as an important factor in understanding the trends in account openings and the type of cards held by clients. However, it could not be ascertained if credit limit was a term used to indicate credit limit, spending limit, and transaction limit for credit cards, debit cards, and debit (prepaid) cards, respectively.
## Data Source
The dataset for this project was gotten from Kaggle, an online platform used for data analysis.
